---
title: File Upload Error
description: How to fix file upload failures.
---

## Symptoms

- File fails to upload
- Error: "Upload failed. Please try again."

## Causes

- File size exceeds limit (50MB)
- Unstable internet connection

## Solution

<Steps>
  <Step title="Check file size">
    Maximum upload size is 50MB per file.
  </Step>
  <Step title="Verify your connection">
    Try refreshing the page and uploading with a stable network.
  </Step>
  <Step title="Try a different browser">
    Some browser extensions or settings may interfere with uploads.
  </Step>
</Steps>
